# Éclat Wine Tour brand-family reference

Public site: `https://eclatwinetour.com/`

A saved HTML snapshot of the homepage was supplied as project reference. Its page metadata identifies the site as **Éclat Wine Tour** and describes personalized Champagne tours in Côte des Bar. The saved page is a WordPress/Divi implementation.

Use this material for **brand-family analysis**, not as implementation code to copy.

Relevant transferable ideas:

- the Éclat name should feel personal rather than corporate;
- photography and lifestyle imagery lead the experience;
- elegant pacing and warmth are more important than dense information architecture;
- Atelier can inherit a sense of intimacy, craftsmanship and premium restraint while developing its own interior-design visual system.

Do not automatically reuse the Wine Tour navigation, WordPress/Divi markup, service structure, legal text, contact data or claims for Atelier.

`Home - Éclat Wine Tour - Personalized Champagne Tours.html`
